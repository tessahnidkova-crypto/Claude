## Kostra v deseti řádcích

Biologikum = léčivo vyrobené živým organismem, velká složitá bílkovina. Proti malým molekulám: nedá se přesně okopírovat (→ **biosimilars**, ne generika), podává se **jen parenterálně**, je **imunogenní**. Hlavní skupiny: monoklonální protilátky (`-mab`), fúzní proteiny (`-cept`), rekombinantní hormony, enzymy a cytokiny, vakcíny, pokročilé terapie (CAR-T). Přínos = vysoká specificita a účinnost tam, kde konvenční léčba selhává. Hlavní rizika = **imunogenita**, **infekce (reaktivace TBC a HBV)**, reakce na podání a cena. Před zahájením se **vždy** screenuje TBC a hepatitidy.

## 1. Definice a vymezení

**Biologické léčivo** = léčivá látka, která je produkována živým organismem nebo z něj získána. Typicky velká, strukturně složitá molekula (nejčastěji bílkovina), vyráběná **rekombinantní DNA technologií** nebo **hybridomovou technologií**.

### Biologikum vs. malá molekula

| | Malá molekula | Biologikum |
|---|---|---|
| Velikost | stovky Da | tisíce až ~150 000 Da |
| Struktura | přesně definovaná | složitá, heterogenní (glykosylace) |
| Výroba | chemická syntéza | živé buňky |
| Podání | často perorálně | **prakticky vždy parenterálně** |
| Imunogenita | nízká | **významná** |
| Kopie | generikum = identické | **biosimilar = vysoce podobné** |
| Stabilita | vysoká | citlivé na teplotu a třepání |

⚠️ **Klasická past:** léčiva s koncovkou `-tinib` (imatinib, erlotinib) jsou **malé molekuly**, ne biologika, přestože jsou to cílené léky. „Cílená léčba" a „biologická léčba" nejsou totéž — cílená léčba je širší pojem.

## 3. Názvosloví monoklonálních protilátek

### Klasický systém (WHO INN)

Skládá se ze čtyř částí: **prefix + cíl + zdroj + `-mab`**

**Cílová skupina** *(infix)*

| Infix | Cíl |
|---|---|
| `-ba(c)-` | bakterie |
| `-ci(r)-` | kardiovaskulární systém |
| `-li(m)-` | imunitní systém |
| `-ne(r)-` | nervový systém |
| `-tu(m)-` | nádor |
| `-ki(n)-` | interleukin |
| `-so(s)-` | kost |

**Zdroj** *(infix)*

| Infix | Původ |
|---|---|
| `-o-` | myší (murine) |
| `-xi-` | chimérická |
| `-zu-` | humanizovaná |
| `-u-` | plně humánní |
| `-a-` | krysí |

**Rozbor příkladů:**

| Název | Rozklad | Znamená |
|---|---|---|
| ri-**tu**-**xi**-mab | nádor + chimérická | anti-CD20, chimérická |
| tras-**tu**-**zu**-mab | nádor + humanizovaná | anti-HER2 |
| inf-**li**-**xi**-mab | imunitní + chimérická | anti-TNF-α |
| ada-**li**-**mu**-mab | imunitní + humánní | anti-TNF-α |

> **Mnemotechnika na zdroj:** myš → chiméra → humanizovaná → humánní = `o → xi → zu → u`. Čím dál v abecedě od „o", tím víc lidské a tím **méně imunogenní**.

### ⚠️ Systém se změnil — a tohle je přesně místo, kde se můžeš rozejít s přednáškou

WHO názvosloví monoklonálních protilátek **dvakrát revidovalo**: kolem roku 2017 zrušilo zdrojový infix a kolem roku 2021 nahradilo samotnou příponu `-mab` několika novými (`-tug`, `-bart`, `-mig`, `-ment`) podle typu molekuly. `[⚠️ ověřit roky i přesné významy]`

**U zkoušky jeď podle toho, co učí tvoje katedra.** Většina českých kurzů pořád učí klasický systém výše, protože všechna zavedená léčiva ho nesou. Kdyby se přednáška lišila, platí přednáška.

## 4. Biosimilars

### Proč to nejsou generika

Generikum malé molekuly je **chemicky identické** s originálem. U biologika to nejde: molekula je velká, vyrábí ji živá buňka a vzniká nevyhnutelná mikroheterogenita (zejména v glykosylaci). Dvě šarže téhož originálu se od sebe mírně liší — natož výrobek jiného výrobce.

**Definice:** biologický přípravek **vysoce podobný** již registrovanému referenčnímu přípravku, **bez klinicky významných rozdílů** v kvalitě, bezpečnosti a účinnosti.

### Jak se registruje

Nestačí prokázat bioekvivalenci jako u generika. Vyžaduje se **srovnávací (comparability) přístup**, stupňovitě:

1. **Analytické srovnání** — základ a nejcitlivější část: struktura, glykosylace, biologická aktivita
2. **Neklinické srovnání** — in vitro, případně in vivo
3. **Klinické srovnání** — farmakokinetika/farmakodynamika, **imunogenita**, obvykle jedna studie účinnosti na citlivé populaci

EU byla **první region s legislativním rámcem pro biosimilars** (EMA); první schválený biosimilar byl somatropin. `[⚠️ ověřit rok — uvádí se okolo 2006]`

### Praktické důsledky

- **Sledovatelnost:** vždy zaznamenat **obchodní název a číslo šarže**, ne jen účinnou látku — kvůli hlášení nežádoucích účinků a imunogenitě
- **Zaměnitelnost a substituce** řeší národní legislativa `[⚠️ ověřit aktuální pravidla v ČR — spadá pod SÚKL]`
- **Význam:** výrazné snížení ceny a zvýšení dostupnosti biologické léčby

---

## 5. Terapeutické přínosy

- **Vysoká cílová specificita** — zásah do konkrétní molekuly či receptoru, méně off-target účinků
- **Účinnost tam, kde konvenční léčba selhává** — revmatoidní artritida, idiopatické střevní záněty, psoriáza, roztroušená skleróza, těžké astma, onkologie
- **Ovlivnění průběhu nemoci**, ne jen symptomů (disease-modifying)
- **Dlouhý poločas** → méně časté podávání (týdny až měsíce)
- Umožnily **cílenou onkologickou léčbu** a imunoterapii nádorů

## 6. Rizika a nežádoucí účinky

| Riziko | Podstata | Poznámka |
|---|---|---|
| **Imunogenita** | tvorba protilátek proti léčivu (ADA) | → **ztráta účinnosti**, reakce; nižší u humánních než chimérických |
| **Infekce** | imunosuprese, oportunní infekce | **nejdůležitější prakticky** |
| **Reaktivace latentní TBC** | zejména anti-TNF | **screening před zahájením povinný** |
| **Reaktivace HBV** | zejména rituximab, anti-TNF | screening povinný |
| **Reakce na podání** | infuzní reakce, anafylaxe, reakce v místě vpichu | |
| **Syndrom z uvolnění cytokinů** | CAR-T, bispecifické protilátky | horečka, hypotenze, může být život ohrožující |
| **Kardiotoxicita** | trastuzumab | anti-TNF kontraindikovány u srdečního selhání NYHA III/IV |
| **Demyelinizace** | anti-TNF | opatrnost u demyelinizačních onemocnění |
| **PML** | natalizumab (JC virus) | progresivní multifokální leukoencefalopatie |
| **Imunitně podmíněné NÚ (irAE)** | checkpoint inhibitory | kolitida, hepatitida, pneumonitida, tyreoiditida, hypofyzitida |
| **Malignity** | riziko lymfomu u anti-TNF | `[⚠️ ověřit — v literatuře diskutováno, ne jednoznačně prokázáno]` |
| **Cena** | | zásadní limitace dostupnosti |
| **Nutnost parenterálního podání** | bílkovina se v GIT rozloží | žádná perorální forma |
| **Chladový řetězec** | citlivost na teplotu a třepání | logistická zátěž |

### Před zahájením biologické léčby — vždy

- **Screening latentní TBC** (IGRA nebo Mantoux + RTG hrudníku)
- **Screening HBV, HCV, HIV**
- Vyloučit **aktivní infekci**
- **Očkování** doplnit ideálně před zahájením — **živé vakcíny jsou během léčby kontraindikované**
